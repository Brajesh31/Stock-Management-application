# Contributing

- Keep frontend and backend changes separated and explain cross-layer API changes.
- Install dependencies using the lockfile in the relevant directory.
- Add or update tests for authentication, item ownership, validation, and UI behavior.
- Never commit database dumps, credentials, JWT secrets, or real customer records.
- Document API contract changes and migration implications.
- Run frontend build and backend syntax/tests before opening a pull request.

Do not weaken authorization or validation to make a test pass.
